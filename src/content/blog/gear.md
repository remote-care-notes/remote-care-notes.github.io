遠隔見守りといっても、特別な機材は要りません。Amazon や楽天で買える普通のスマートホーム機器の組み合わせで、合計1〜2万円。家にある既存の家電は、ほぼそのまま使います。

## ハードウェア（合計1〜2万円くらい）

| 機材 | 役割 | 目安価格 |
|------|------|---------|
| Android スマホ 1台 | 操作する側の端末（古いスマホ流用可） | 0円〜（手元にあれば） |
| Tapo カメラ（C200推奨） | 見守り・双方向通話 | 3,000〜5,000円 |
| SwitchBot 温湿度計 | 室温・湿度の遠隔モニタリング | 2,000円前後 |
| SwitchBot Hub mini / Hub 2 | 赤外線リモコン家電を遠隔操作（エアコン・照明・テレビ等） | 4,000〜8,000円 |
| SwitchBot 指スイッチ（必要に応じて） | 赤外線非対応の物理ボタン家電を押す（除湿機など） | 4,000円前後 |
| Echo Dot（あれば便利） | 本人側の音声操作（タイマー・天気予報・コマンド） | 5,000円前後 |

最低構成（カメラ + 温湿度計 + Hub mini）なら **約1万円**。Echo Dot や指スイッチを足しても **2万円で収まります**。

### セール時に買うのが正解

このへんの機材、定価で買う必要なし。

- **Amazon ブラックフライデー** （11月下旬）
- **Amazon プライムデー** （7月）
- **楽天お買い物マラソン** （年に何回か）

このあたりで30〜40%引きになるので、急ぎでなければセールまで待つのを推奨します。家電量販店のポイントよりずっと安いです。

我が家も全部セール時に揃えました。

## アプリ（全部無料）

- **Tapo**（カメラ用）
- **SwitchBot**（温湿度計・Hub・指スイッチ用）
- **Alexa**（Echo Dot 使う場合）
- **Split Screen Launcher**（Android の画面分割を使いやすくする）

全部無料です。介護当事者から課金してほしいとは思っていません。

アプリの組み合わせ方や運用は、別の章で詳しく書きます。

## 既存の家電は買い替えなくてよい

実家にある家電はそのまま使います。買い替え前提ではありません。

- エアコン
- 照明（シーリングライト）
- テレビ
- 加湿器・除湿機・ストーブ・サーキュレーター など

エアコン・照明・テレビは赤外線リモコンがあれば SwitchBot Hub から遠隔操作できます。リモコンが赤外線じゃない（物理ボタン）家電なら、SwitchBot 指スイッチで物理的にボタンを押す方式で対応。

ストーブやサーキュレーターは敢えて自動化しない選択もあります（理由は別の章で）。

## 必須・任意の整理

| 機材 | 必須？ |
|------|------|
| Android端末（操作する側） | 必須 |
| Tapoカメラ × 1台 | 必須 |
| SwitchBot温湿度計 | ほぼ必須（環境把握の基準になる） |
| SwitchBot Hub mini | 赤外線家電を遠隔操作したいなら必須 |
| SwitchBot 指スイッチ | 物理ボタンの家電がある場合のみ |
| Echo Dot | 本人側で音声操作したい場合（あれば便利） |

最低限、**カメラ1台と温湿度計1個**から始められます。あとは必要に応じて足していけば OK。最初から全部揃えなくていいです。

## まとめ

- 1〜2万円、無料アプリ4つ、既存家電そのままで遠隔見守りは組める
- 急がないならセール時に買う（30〜40%引き）
- 一気に揃えなくていい。カメラ + 温湿度計から始めればいい
