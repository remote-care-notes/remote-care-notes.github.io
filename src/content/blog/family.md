離れて暮らしている親の介護を一人で全部やろうとすると、長続きしません。「自分が見守らないと」と気負うほど消耗するし、逆に距離があるからこそ「ちゃんと見られているのか」という不安も大きくなります。

兄弟姉妹がいるなら、家族で分担するのが現実的です。最初から完璧に決める必要はなく、お互いの距離と得意なことに合わせて自然に役割が分かれていきます。

## 距離が違うから役割も違う

我が家の場合、姉が母の家の近くに住んでいるので、こんな分担になっています。

- **自分（遠方）**：システム担当
  - カメラ・センサー・家電制御の設定や見直し
  - 毎日の様子確認、室温・湿度のチェック
  - 訪問サービス事業所との細かい連絡
- **姉（近所）**：駆けつけ担当
  - 何かあったときに直接駆けつける
  - 対面で話す、買い物の代行
  - 病院の付き添い、書類対応

これは最初から決めた分担というより、お互いの距離と得意なことから自然に分かれた結果です。

「あの人が遠いから、何もできない」じゃなくて、「遠いからこそできること」「近いからこそできること」がそれぞれにある、という見方をすると整理しやすいです。

## カメラのアカウント共有が一番効く

家族分担で実装上いちばん効くのが、**Tapo のアカウント共有** です。

- Tapo アプリには「家族メンバーを招待する」機能があり、招待された人は同じカメラを別の端末から見られる
- 自分のアカウントに姉を招待すれば、追加費用ゼロで姉も同じカメラを使える
- お互いに見られる時間帯が違うので、結果的に二人で見守れる

我が家のパターン：

- 平日の昼間（姉が仕事や用事で忙しい）→ 自分が確認
- 夜（姉が自宅に戻って落ち着いた時間）→ 姉が確認
- 自分が出張中・会議中 → 姉が見ておく
- 姉が外出中 → 自分が見ておく

二人で交代に見ているわけじゃなくて、それぞれが自分のタイミングで開いて、結果的に「どちらかが見ている時間が長くなる」状態です。

## 異変に気付いたときの流れ

カメラで「いつもと違うな」と気付いたとき、いきなり駆けつけることはほとんどありません。順序があります。

1. **まず電話で本人に確認**：「お母さん、大丈夫？」
2. **本人が応答する** → 状態を聞く、必要なら声かけだけで終わり
3. **応答がない、様子がおかしい** → 姉に連絡して駆けつけてもらう
4. **明らかに緊急** → 救急車を呼ぶ、必要なら近隣の協力者にも連絡

ほとんどの場合、1〜2 で済みます。「カメラで気になる → 電話 → 様子確認」というワンクッションがあると、過剰な駆けつけを避けつつ、見逃しも防げます。

姉も同じ流れで動きます。姉が気付いて、本人に電話して、必要なら駆けつける。自分のところに連絡が来ることもあれば、来ないこともある。それでいいです。

## 連絡は LINE グループひとつで

兄弟姉妹間のやりとりは、特別な仕組みは要りません。普段使っている **LINE グループひとつ** で十分です。

- 日常：「今カメラ見たけど普通やった」「今日訪問看護来るで」のような短いやりとり
- 共有：母の状態の変化、訪問サービスの予定、買ってきてほしいもの
- 緊急時：電話に切り替える

道具はシンプルなほどいいです。普段使っているものをそのまま使えば、習慣になります。

## 心理的な負担も分散される

家族分担は、物理的な動きだけじゃなく **心理的な負担の分散** にも効きます。

- 一人で背負うと、些細なことも気にしすぎてしまう
- 二人で見ていれば「これは様子見でいいかな」と相談できる
- 「自分が見ていない時間に何かあったら」という不安が薄まる

これはカメラの共有で自然に生まれる効果で、お金もかかりません。気付いたことを気軽に「ちょっと見てくれる？」と頼めるだけで、随分気持ちが楽になります。

## 役割の濃淡は時期によって動く

「自分が中心、姉がサポート」と決めても、状況によって入れ替わることがあります。

- 自分の仕事が忙しい時期 → 姉中心
- 姉が体調を崩したとき → 自分中心
- 訪問サービスが増えた時期 → 二人とも見守り役
- 母の状態が安定している時期 → どちらも軽め

固定的に決めず、その時その時で柔軟に動けるほうが、長く続きます。「役割の引き継ぎ」を意識的にやる場面はほとんどなく、自然に揺らいで戻ります。

## 設計の方針

- **離れている家族と近くにいる家族で役割を分ける**：物理的にできることが違うので、無理に同じことをやらない
- **カメラのアカウント共有が一番効く**：追加費用ゼロで体制が二人になる
- **異変 → 電話 → 駆けつけ の順序を守る**：いきなり駆けつけない
- **心理的な負担も二人で分散する**：相談できる相手がいるだけで違う

## まとめ

- 一人で全部抱え込まない、家族で分担する
- Tapo のアカウント共有で、追加費用ゼロの二人体制
- 異変は電話で確認 → 必要なら駆けつけの順序
- 連絡は LINE グループひとつで十分
- 役割の濃淡は時期で動く、固定しない

兄弟姉妹がいない場合や、近くに頼れる家族がいない場合もあると思います。その場合はケアマネジャーや地域包括支援センターを家族の代わりに据える、という考え方もあります。「自分一人で全部」を避けることが本質です。
